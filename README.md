# EXERCICIOS-PHP

##  Pré-requisitos:
É necessário ter instalado:
- Docker
- Docker Compose
  
## Como rodar:
1-É necessário clonar o repósitorio git copiando o link diretamente onde deseja deixar a pasta ou ultizando git clone + o link no terminal


2-Acesse a pasta do projeto


3-Inicie o docker: docker compose up


4-Acesse no navegador: http://localhost:8181
